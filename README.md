# Shift App — учёт рабочих смен (пользовательская часть)

Веб-реализация пользовательской части мобильного приложения для отметки начала и окончания рабочей смены согласно ТЗ (React 18 + TypeScript + Vite). Бизнес-логика изолирована в модулях (`src/lib`, `src/store.ts`) и переносима в Flutter/React Native.

## Возможности (по ТЗ)

- **Авторизация** (6.1): вход по телефону/email + пароль, показ/скрытие пароля, сохранение сессии, обработка ошибок входа. Демо-доступ: `demo@shift.ru` / `1234`.
- **Главный экран** (6.2): статус смены, время начала, комментарий, индикаторы сети и синхронизации, крупные кнопки «Начать работу» / «Завершить работу».
- **Отметки с геолокацией** (6.3–6.5): one-shot запрос координат в момент действия (без фонового отслеживания), экран подтверждения с необязательным комментарием (до 1000 символов), экран ошибки геолокации, защита от повторных нажатий.
- **Офлайн-режим и синхронизация** (6.6, 8–10): хранение в IndexedDB (UUID события, локальное время, часовой пояс, координаты, статус), автосинхронизация при появлении сети, экспоненциальный backoff, строгий порядок start→end, идемпотентность по `event_id`, восстановление после перезапуска.
- **История** (6.8): отметки за 30 дней, сгруппированные по датам, с комментариями и статусами.
- **Профиль** (6.9): данные сотрудника, версия приложения; выход заблокирован при наличии неотправленных отметок.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 30 тестов (vitest), приемочные критерии ТЗ 17
npm run build      # прод-сборка в dist/
npm run preview    # предпросмотр сборки
```

## Бэкенд

По умолчанию работает встроенный mock-сервер (идемпотентность, проверка порядка событий). Для подключения реального REST API задайте переменную окружения `VITE_API_URL` (эндпоинты: `POST /auth/login`, `POST /events`, `GET /events`).

## Структура

```
src/
  types.ts            доменные типы и константы
  i18n.ts             тексты интерфейса (русский)
  lib/api.ts          сетевой слой (REST + mock)
  lib/storage.ts      локальное хранилище (IndexedDB)
  lib/location.ts     геолокация (one-shot)
  lib/comment.ts      валидация комментария
  lib/time.ts         локальное время и часовой пояс
  store.ts            бизнес-логика (zustand)
  screens/            Экраны: Login, Main, ShiftConfirm, History, Profile
  test/               юнит- и интеграционные тесты
```
